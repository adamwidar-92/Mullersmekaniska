# Müller Mekaniska AB

Välkommen till **Müller Mekaniska AB** - en ledande tillverkare av högindustriella mekaniska komponenter och maskindelar.

## Om oss

Müller Mekaniska AB är ett etablerat företag inom mekanisk tillverkning specialiserat på produktion av precision-komponenter och maskindelar. Med decenniers erfarenhet erbjuder vi världsklass tillverkning, CAD-ritningssamordning och teknisk rådgivning för industriella och kommersiella kunder globalt.

## Våra tjänster

✓ **Precision-tillverkning** - Högkvalitativa mekaniska komponenter  
✓ **CAD-designsamordning** - Från idé till produktion  
✓ **Prototypframställning** - Snabbt från koncept till verklighet  
✓ **Serieproduktion** - Skalbar tillverkning för alla volymer  
✓ **Global leverans** - Vi skickar till över 50 länder  
✓ **Teknisk rådgivning** - Expert-stöd genom hela projektets livscykel

## Webbutveckling

Denna repository innehåller källkoden för Müller Mekaniskas webbplats, utvecklad med Vue 3 och Vite.

### Teknikstack

- **Frontend**: Vue 3 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Tools**: Node.js, npm

### Kom igång med utveckling

```bash
npm install
npm run dev       # Utvecklingsserver
npm run build     # Production build
npm run type-check # TypeScript-kontroll
```
